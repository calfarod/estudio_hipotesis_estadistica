Caso 5: Evaluación de Impacto de una Campaña Publicitaria en la Intención de Compra

1. Contexto del Problema y Planteamiento

Una marca de consumo masivo lanza una campaña en medios digitales para revitalizar un producto. El equipo de Investigación de Mercados necesita evaluar si la estrategia incrementó de forma estadísticamente significativa la intención de compra de los consumidores.

Para ello, se selecciona una muestra aleatoria de n = 30 consumidores. A cada participante se le mide la intención de compra en una escala métrica continua de 0 a 100 puntos en dos momentos del tiempo: ANTES (Pre) y DESPUÉS (Post) de ser expuestos a la campaña. Se trabajará con un nivel de significancia de α = 0,05 (5%).

2. Fundamentos Teóricos y Elección de la Herramienta Metodológica

Criterios de Elección Metodológica:

  • Tipo de Variable: Cuantitativa Métrica (Intención de compra, medida de 0 a 100 puntos)[cite: 2].
  • Número de Muestras: 2 mediciones[cite: 2].
  • Relación entre Muestras: Pareadas / Relacionadas (Mismo Grupo)[cite: 2]. Cada consumidor actúa como su propio control, lo que elimina la variabilidad individual entre sujetos y aumenta la potencia estadística del test.
  • Prueba Estadística Aplicable: Prueba t de Student para Muestras Emparejadas / Repetidas (Caso 5)[cite: 2].

Definición de la Variable de Diferencia (d)

Para cada sujeto i (donde i = 1, 2, ..., n), calculamos el cambio individual generado por la campaña:

di = Xpost, i - Xpre, i

La prueba evalúa si la media poblacional de estas diferencias (μd) es significativamente mayor que cero.

4. Resolución Paso a Paso

Paso 1: Formulación de Hipótesis

  • Hipótesis Nula (H0): μd ≤ 0 (La campaña no aumentó la intención de compra; la diferencia media Post - Pre es menor o igual a cero).
  • Hipótesis Alternativa (H1): μd > 0 (La campaña aumentó significativamente la intención de compra; la diferencia media Post - Pre es estrictamente positiva).

Paso 2: Resumen de Estadísticos Descriptivos de las Diferencias

A partir de los 30 pares de datos calculamos:

  • Promedio Pre-Campaña (X̄pre): 47,40 puntos
  • Promedio Post-Campaña (X̄post): 54,67 puntos
  • Diferencia Media Observada (d̄): +7,27 puntos
  • Desviación Estándar de las Diferencias (sd): 1,98 puntos
  • Tamaño de Muestra (n): 30

Paso 3: Cálculo del Error Estándar de la Diferencia (SEd)

Fórmula del Error Estándar de la media muestral de las diferencias:

SEd = sd / √n

SEd = 1,98 / √30 = 1,98 / 5,4772 = 0,3615

Paso 4: Cálculo del Estadístico t de Student (tcalc)

Fórmula del estadístico de prueba:

tcalc = (d̄ - μ0) / SEd

tcalc = (7,27 - 0) / 0,3615 = 20,11

Paso 5: Grados de Libertad, Valor Crítico y Valor p

  • Grados de Libertad (df): n - 1 = 30 - 1 = 29
  • Valor Crítico (α = 0,05, unilateral derecha): t0.05, 29 = 1,699
  • Valor p (p-value): Con t = 20,11 y df = 29, el p-valor < 0,001 (prácticamente igual a 0).

Paso 6: Conclusión e Interpretación de Mercado

Decisión Estadística: Como tcalc (20,11) > tcrítico (1,699) y p-valor < 0,001 < 0,05, se rechaza la hipótesis nula (H0).

Interpretación de Negocio: Con un 95% de confianza, existe evidencia estadísticamente significativa para afirmar que la campaña publicitaria incrementó de manera efectiva la intención de compra de los consumidores, logrando un aumento promedio estimado de 7,27 puntos en la escala de medición.

5. Código en Python para Verificación y Cálculo Exacto

import numpy as np
import pandas as pd
from scipy import stats

# 1. Simulación de los 30 datos de ejemplo (semilla para reproducibilidad)
np.random.seed(42)
intencion_pre = np.random.normal(loc=45, scale=10, size=30).round().astype(int)
# Se simula un incremento real promedio de +8.5 puntos con variabilidad
intencion_post = intencion_pre + np.random.normal(loc=3.5, scale=8, size=30).round().astype(int)

df = pd.DataFrame({"Pre": intencion_pre, "Post": intencion_post})

# 2. Formulación de hipótesis
print("Ho: d_media <= 0 (La campaña no aumentó la intención de compra, no hay cambio significativo.)")
print("Ha: d_media > 0 (La campaña Sí aumentó la intención de compra.)")

# 3. Resumen descriptivas
df['Diferencia'] = df['Post'] - df['Pre']
d_media = df['Diferencia'].mean()
s_d = df['Diferencia'].std(ddof=1)
n = len(df)

# 4. Cálculo del Error Estándar de la Diferencia
se_d = s_d / np.sqrt(n)

# 5. Imprimir resultados descriptivos
print("--- RESUMEN DESCRIPTIVO ---")
print(f"Media Pre:                  {df['Pre'].mean():.2f}")
print(f"Media Post:                 {df['Post'].mean():.2f}")
print(f"Diferencia Media (d_bar):   {d_media:.2f}")
print(f"Desviación Estándar (s_d):  {s_d:.2f}")
print(f"Error Estándar (SE_d):      {se_d:.4f}")

# 6. Prueba t para Muestras Emparejadas (scipy.stats)
# Nota: 'alternative="greater"' evalúa si Post es estrictamente mayor que Pre
# greater le indica a Python que ejecute una prueba de hipótesis unilateral (de una sola cola a la derecha)
t_stat, p_val = stats.ttest_rel(df["Post"], df["Pre"], alternative="greater")
t_calc_manual = (d_media - 0) / se_d

# 7. Impresión de resultados
print(df)
print("--- PRUEBA T MUESTRAS EMPAREJADAS (CASO 5) ---")
print(f"❤️Diferencia Media (Post - Pre): {d_media:.2f}")
print(f"Desviación Estándar Dif.     : {s_d:.2f}")
print(f"Estadístico t calculado      : {t_stat:.4f}")
print(f"Estadístico t_calc_manual    : {t_calc_manual:.4f}")
print(f"Grados de libertad (df)      : {len(df) - 1}")
print(f"Valor p (unilateral)         : {p_val:.5f}")

if p_val < 0.05:
    print(
        "\nDecisión: Se RECHAZA H0. La campaña Sí aumentó la intención de compra."
    )
else:
    print("\nDecisión: NO se rechaza H0. No hay cambio significativo.")
