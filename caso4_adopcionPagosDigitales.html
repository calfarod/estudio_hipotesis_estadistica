Solución Paso a Paso

Paso 1: Planteamiento de Hipótesis

  • Hipótesis Nula (H0): p₁ ≤ p₂ (La tasa de adopción en Corporativos es menor o igual que en Estándar).
  • Hipótesis Alternativa (H1): p₁ > p₂ (La tasa de adopción en Corporativos es significativamente superior a la del segmento Estándar).

Paso 2: Estadísticos Muestrales

Grupo / Segmento Muestra (n) Éxitos (x) Proporción Muestral (p̄)
Muestra 1: Corporativo 150 96 0,6400 (64,0%)
Muestra 2: Estándar 150 69 0,4600 (46,0%)
Diferencia Observada - - +0,1800 (+18,0%)

Paso 3: Cálculo del Estadístico de Prueba Z

Métrica Valor / Estadístico
Proporción Ponderada Combinada (p̄c) (96 + 69) / (150 + 150) = 165 / 300 = 0,5500
Error Estándar de Diferencia (SE) √[ 0,55 × (1 - 0,55) × (1/150 + 1/150) ] = 0,0576
Estadístico Z Calculado (Zcalc) (0,6400 - 0,4600) / 0,0576 = 3,1248
Valor Crítico (Zα para α = 0,05) 1,6449
Valor p (p-value) P(Z > 3,1248) = 0,0009

Paso 4: Decisión Estadística e Interpretación

Criterio de Decisión:

  • Por Valor p: p = 0,0009 < α = 0,05 → Se rechaza H0.
  • Por Valor Crítico: Zcalculado (3,1248) > Zcrítico (1,6449) → Se rechaza H0.

Conclusión e Impacto Comercial: Existe evidencia estadística altamente significativa (p < 0,001) de que el segmento Corporativo adopta el Autopago a una tasa muy superior (+18% de brecha). En la arquitectura de la app, activaremos el Autopago de forma predeterminada para cuentas Corporativas y aplicaremos campañas de incentivo (cashback) en el segmento Estándar.

Código en Python (`caso4_2proporciones.py`)

import numpy as np
from scipy import stats
from statsmodels.stats.proportion import proportions_ztest

# 1. Datos resumidos del experimento
exitos = np.array([96, 69])   # [Corporativo, Estandar]
muestras = np.array([150, 150])

p1_hat = exitos[0] / muestras[0]  # 64.0%
p2_hat = exitos[1] / muestras[1]  # 46.0%
alpha = 0.05

# 2. Ejecutar la Prueba Z para 2 Proporciones Independientes (Una cola: 'larger')
z_stat, p_value = proportions_ztest(count=exitos, nobs=muestras, alternative='larger')
z_critico = stats.norm.ppf(1 - alpha)

# 3. Salida de Resultados
print("--- PRUEBA Z PARA 2 PROPORCIONES INDEPENDIENTES ---")
print(f"Proporción Corporativo (p1_hat): {p1_hat:.2%}")
print(f"Proporción Estándar    (p2_hat): {p2_hat:.2%}")
print(f"Diferencia Muestral:             {(p1_hat - p2_hat):.2%}")
print(f"Estadístico Z calculado:        {z_stat:.4f}")
print(f"Valor Crítico Z (alpha={alpha}):   {z_critico:.4f}")
print(f"Valor p (p-value):              {p_value:.4f}")

print("\n--- DECISIÓN DE PRODUCTO / ARQUITECTURA ---")
if p_value < alpha:
    print("✅ RECHAZAR H0: Los usuarios Corporativos adoptan la función a mayor tasa.")
else:
    print("❌ NO RECHAZAR H0: No se observa diferencia significativa entre segmentos.")

Guía de Ejecución en Jamovi

  1. Copia el bloque plano de 300 datos CSV de la sección superior y pégalo en una hoja limpia de Jamovi.
  2. Define la columna Segmento como variable Nominal (Valores: Corporativo, Estandar).
  3. Define la columna Adopto_Autopago como variable Nominal (Valores: 1, 0).
  4. Dirígete a la pestaña Analyses → Frequencies → Contingency Tables (Independent Samples - X²).
  5. Mueve Segmento al casillero Rows (Filas) y Adopto_Autopago a Columns (Columnas).
  6. En las opciones de la izquierda, bajo Cells, marca la casilla Row percentages para observar las proporciones del 64% vs 46%.
  7. Bajo Statistics, verifica la prueba de Chi-Square (X²) o activa Difference in proportions para obtener el resultado exacto.
