Caso 2: Asociación entre Segmento de Cliente y Medio de Pago Preferido (Prueba Chi-Cuadrado de Independencia)

Contexto del Problema

Una cadena de supermercados desea optimizar sus cajas de pago. El equipo de Investigación de Mercados quiere saber si la preferencia del medio de pago (Efectivo, Tarjeta de Débito/Crédito, App Móvil) depende del segmento de edad del cliente (Jóvenes: < 30 años, Adultos: 30 a 50 años, Adultos Mayores: > 50 años).

Se realiza una encuesta a una muestra aleatoria de 150 clientes en la que se registran ambas variables cualitativas. Se trabajará con un nivel de significancia de α = 0,05 (5%).

Solución Paso a Paso

Paso 1: Formulación de Hipótesis

  • Hipótesis Nula (H0): El medio de pago preferido es independiente de la edad del cliente (No hay relación entre las variables).
  • Hipótesis Alternativa (H1): El medio de pago preferido depende de la edad del cliente (Existe asociación significativa entre las variables).

Paso 2: Construcción de la Tabla de Contingencia (Frecuencias Observadas O)

Segmento / Medio Pago App Móvil Efectivo Tarjeta Total
Joven 24 8 18 50
Adulto 7 14 29 50
Adulto Mayor 5 30 15 50
Total 36 52 62 150

Paso 3: Frecuencias Esperadas (E) bajo H0

La frecuencia esperada en cada celda representa los conteos teóricos si las dos variables fueran independientes:

Eij = (Total Filai × Total Columnaj) / N

  • Para la celda (Joven, App Móvil): E = (50 × 36) / 150 = 12
  • Para la celda (Joven, Efectivo): E = (50 × 52) / 150 = 17,33
  • Para la celda (Joven, Tarjeta): E = (50 × 62) / 150 = 20,67

(De igual forma para las demás celdas).

Paso 4: Cálculo del Estadístico Chi-Cuadrado (χ²)

Aplicamos la fórmula sumando sobre las 9 celdas de la tabla:

χ² = ∑ [ (O - E)² / E ]

χ² = [ (24 - 12)² / 12 ] + [ (8 - 17,33)² / 17,33 ] + ... + [ (15 - 20,67)² / 20,67 ] = 38,29

Paso 5: Grados de Libertad, Valor Crítico y Valor p

  • Grados de Libertad (df): (Filas - 1) × (Columnas - 1) = (3 - 1) × (3 - 1) = 4
  • Valor Crítico (χ²0.05, 4): 9,488
  • Valor p (p-value): Con χ² = 38,29 y df = 4, el valor p < 0,001.

Paso 6: Conclusión e Interpretación

Decisión: Como p < 0,001 < 0,05 (y además χ²calc = 38,29 > 9,488), se rechaza la hipótesis nula (H0).

Interpretación de Mercado: Existe una asociación altamente significativa entre el segmento de edad y la preferencia del medio de pago. Los jóvenes muestran un uso marcadamente superior de la App Móvil, mientras que los adultos mayores mantienen preferencia por el efectivo y los adultos por tarjetas.

Código en Python para verificación y cálculo exacto

import pandas as pd
import numpy as np
from scipy import stats

# 1. Crear el Dataset
edades = (['Joven'] * 50) + (['Adulto'] * 50) + (['Adulto_Mayor'] * 50)
medios_joven = ['App_Movil']*24 + ['Efectivo']*8 + ['Tarjeta']*18
medios_adulto = ['App_Movil']*7 + ['Efectivo']*14 + ['Tarjeta']*29
medios_mayor = ['App_Movil']*5 + ['Efectivo']*30 + ['Tarjeta']*15

medios = medios_joven + medios_adulto + medios_mayor

df = pd.DataFrame({'Edad': edades, 'MedioPago': medios})

# 2. Tabla de contingencia (Frecuencias Observadas)
tabla_contingencia = pd.crosstab(df['Edad'], df['MedioPago'])

# 3. Prueba Chi-Cuadrado de Independencia
chi2_stat, p_val, dof, expected = stats.chi2_contingency(tabla_contingencia)

# 4. Valor Crítico para alpha = 0.05
alpha = 0.05
chi2_critico = stats.chi2.ppf(1 - alpha, dof)

# 5. Salida de Resultados
print("--- TABLA DE CONTINGENCIA (OBSERVADOS) ---")
print(tabla_contingencia)
print("\n--- RESULTADOS PRUEBA CHI-CUADRADO ---")
print(f"Estadístico Chi2 calculado: {chi2_stat:.4f}")
print(f"Grados de libertad (df):    {dof}")
print(f"Valor crítico (alpha 0.05): {chi2_critico:.4f}")
print(f"Valor p (p-value):          {p_val:.4e}")

if chi2_stat > chi2_critico:
    print("\nDecisión: Se RECHAZA H0 (Las variables están asociadas).")
else:
    print("\nDecisión: NO se rechaza H0 (Las variables son independientes).")
