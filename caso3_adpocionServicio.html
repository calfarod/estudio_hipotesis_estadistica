Caso 3: Validación de Adopción de un Nuevo Servicio de Movilidad (Prueba Z para 1 Proporción)

Contexto del Problema

Una plataforma de transporte urbano (Uber del futuro) planea lanzar a nivel nacional la función "Viaje Silencioso & Climatizado", diseñada para resolver la fatiga social de los pasajeros en viajes de trabajo.

Para justificar la inversión en desarrollo e infraestructura, la gerencia exige que al menos el 30% (p₀ = 0,30) de los usuarios adopte la función durante la prueba piloto. Se evalúa una muestra de n = 200 usuarios en una ciudad piloto con un nivel de significancia de α = 0,05.

Resumen del piloto: 72 éxitos (Adoptaron el servicio) y 128 fracasos.

Solución Paso a Paso

Paso 1: Planteamiento de Hipótesis

  • Hipótesis Nula (H0): p ≤ 0,31 (La tasa de adopción es igual o inferior al 31%; el piloto no alcanza la meta).
  • Hipótesis Alternativa (Ha): p > 0,31 (La tasa de adopción es superior al 31%; el piloto es un éxito comercial).

Paso 2: Estadísticos Muestrales

Estadístico Símbolo Valor Muestral
Tamaño de Muestra n 200
Casos de Éxito Observados x 72
Proporción Muestral p̄ (p-hat) 0,3600 (36,1%)
Proporción Hipotética (Meta) p1 0,3000 (30,0%)
Error Estándar de la Proporción SE = √[p₀(1-p₀)/n] 0,0324

Paso 3: Cálculo del Estadístico de Prueba Z

Fórmula aplicada para el estadístico Z:

Z = (p̄ - p0) / SE = (0,3600 - 0,3000) / 0,0324 = 1,8519
Métrica Fórmula / Método Valor
Valor Crítico (Una Cola) Zα (α = 0,05) 1,6449
Valor p (p-value) P(Z > 1,8519) 0,0320

Paso 4: Decisión Estadística e Interpretación

Criterio de Decisión:

  • Por Valor p: p = 0,0320 < α = 0,05 → Se rechaza H0.
  • Por Valor Crítico: Zcalculado (1,8516) > Zcrítico (1,6449) → Se rechaza H0.

Conclusión de Negocio: Con un 95% de confianza, existe evidencia estadística suficiente para afirmar que la tasa de adopción del servicio "Viaje Silencioso" superó la meta del 30%, alcanzando un 36%. Se aprueba el despliegue a escala nacional.

Código en Python para verificación y cálculo exacto

import numpy as np
import pandas as pd
from statsmodels.stats.proportion import proportions_ztest
from scipy import stats

# 1. Configuración de datos del experimento
exitos = 72       # Usuarios que activaron la función
nobs = 200        # Muestra total evaluada
p_0 = 0.30        # Meta mínima de adopción (30%)
alpha = 0.05      # Nivel de significancia

# 2. Ejecutar la Prueba Z para 1 Proporción (Una cola hacia la derecha: 'larger')
z_stat, p_val = proportions_ztest(count=exitos, nobs=nobs, value=p_0, alternative='larger')

# 3. Valor crítico de Z para alpha = 0.05
z_critico = stats.norm.ppf(1 - alpha)

# 4. Salida de Resultados
print("--- PRUEBA Z PARA UNA PROPORCIÓN (ADOPCIÓN DE PRODUCTO) ---")
print(f"Proporción observada (p-hat): {exitos/nobs:.4f} ({exitos/nobs:.1%})")
print(f"Estadístico Z calculado:     {z_stat:.4f}")
print(f"Valor Crítico (Z_alpha):     {z_critico:.4f}")
print(f"Valor p (p-value):           {p_val:.4f}")

print("\n--- DECISIÓN DE PRODUCTO / COMERCIAL ---")
if p_val < alpha:
    print("Resultado: SE RECHAZA H0.")
    print("Conclusión: La adopción superó la meta requerida. Desplegar en producción.")
else:
    print("Resultado: NO SE RECHAZA H0.")
    print("Conclusión: La adopción no alcanza la meta. Ajustar estrategia o interfaz.")
